# 🦷 DavanteDent - Gestión de Citas Odontológicas

![Logo DavanteDent](img/davantedent.png)

## 📋 Descripción del Proyecto
DavanteDent es una aplicación web de **Front-end** diseñada para la gestión integral de citas diarias en una clínica dental. Este proyecto ha sido desarrollado como parte del módulo **Desarrollo Web en Entorno Cliente (DAW)**, cumpliendo con los requisitos de arquitectura cliente/servidor y manipulación dinámica del DOM.

La aplicación permite realizar el ciclo completo de gestión de datos (**CRUD**): Crear, Leer, Actualizar y Eliminar citas de pacientes, garantizando la persistencia de la información mediante el uso de cookies.

## 🚀 Funcionalidades Clave
- **Gestión Dinámica (DOM):** Inserción y borrado de registros en tiempo real sin recargar la página.
- **Validación Avanzada:** Comprobación de integridad de datos (DNI español, formato de teléfono y campos obligatorios).
- **Persistencia de Datos:** Almacenamiento local mediante Cookies para mantener la información tras refrescar el navegador.
- **Modo Edición:** Capacidad de recuperar datos existentes al formulario para su modificación.
- **Interfaz Profesional:** Diseño responsivo y elegante adaptado al sector sanitario.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica del documento.
- **CSS3:** Diseño avanzado mediante Flexbox y Grid, incluyendo tipografías personalizadas (Google Fonts).
- **JavaScript (Vanilla):** Lógica de programación, gestión de eventos y manipulación de la jerarquía del DOM.
- **JSON:** Formateo de datos para su almacenamiento en cookies.
- **Git/GitHub:** Control de versiones y despliegue del repositorio.
